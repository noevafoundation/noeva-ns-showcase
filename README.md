# NOEVA · Network School Showcase

A short presentation deck (5 slides, ~3 minutes) on sovereign identity architecture and what I've been building at Network School.

## View the deck

Live: <https://noevafoundation.github.io/noeva-ns-showcase/>

## Local

Open `index.html` in a browser, or serve the directory:

```sh
python3 -m http.server 8000
```

Navigation: `←` / `→`, `Space`, `PgUp` / `PgDn`, number keys. Press `R` to reset to slide 1.

## Files

- `index.html` — the deck itself (1920×1080, letterboxed and scaled to fit)
- `deck-stage.js` — the `<deck-stage>` web component (scaling, nav, speaker notes, print-to-PDF)
